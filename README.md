# Expense Dashboard

A modern expense tracking dashboard built with React and Recharts.

## Features

- Add income/expense transactions with amount, category, date, and description
- Summary cards showing balance, total income, and total expenses
- Pie chart of expenses by category
- Bar chart of monthly income vs expenses
- Line chart of balance over time
- Transaction list with delete functionality
- Filter by category and date range
- Export filtered transactions to CSV
- Data persisted to localStorage
- Dark theme with teal accent

## Categories

Food, Transport, Entertainment, Bills, Shopping, Health, Education, Other

## Tech Stack

- React (Vite)
- Recharts

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
